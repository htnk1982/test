# PDRM：D.O.I.の公開制作証言と、音符追従型サブベース補完への設計変更

作成日：2026-09-05
状態：公開資料の調査と実験仕様。DSP実装・音源生成・聴感検証は未実施。
変更範囲：本書のみ。採用C、既存のDSP、runtime、productionのRound制限を変更しない。

## 1. 結論

D.O.I.が関わったKIRINJIの制作は、本プロジェクトの参照として有用である。公開インタビューには、従来の中域中心の音像から低域・キックを重視する方向へ移り、同時代の曲と並べた際のレンジ感を求めたという当事者の説明がある。[S1][S2]

ただし、D.O.I.が特定曲で『曲のキーに合わせた正弦波を追加した』という工程や、その周波数・音量・プラグイン設定は、今回確認した資料では裏付けられていない。これをD.O.I.固有の秘伝として実装しない。

サブベースのレイヤー追加、入力に追従するサブハーモニック生成は、別途、メーカーの技術説明と制作担当者の使用証言で確認できる手法である。[S5][S6][S7] 採用率を示す統計は得られていない。『現代曲の大半が実施している』『参照との違いは必ずこれが原因』とはしない。

PDRMへの移植対象は、特定製品の模倣ではなく、次の制御である。

**音楽の低音パートを読み取り、既存成分の調整だけで足りない箇所には、演奏に従う低域レイヤーを補う。曲のキーだけから一定の低音を鳴らし続けない。**

## 2. 確認できた制作事実

### KIRINJI

2019年『cherish』期のインタビューで、堀込高樹はD.O.I.がミックスした「killer tune kills me feat. YonYon」を低域と広がりの基準にしたと説明している。千ヶ崎学は録音段階から低域と演奏のニュアンスを両立させる工夫を述べている。[S1]

Qeticの取材では、打ち込みのビートと生ベースの併用、低域・歌・背後の楽器の関係が語られる。これは、完成2mixの低域だけを機械的に上げたことの証拠ではなく、演奏・録音・ミックスを含む制作判断の証拠である。[S2]

「killer tune kills me」の公式クレジットでもD.O.I.のミックス担当は確認できる。[S3]

### 松原みき「真夜中のドア」

D.O.I.によるOriginal club mixは2003年のプロモーション用リミックスとして公式に確認できる。2023 mixは吉田保による別バージョンなので混同しない。[S4a][S4b]

制作に関わった音楽マーケッターの回想では、Original club mixはオリジナルのアナログ・マルチをデジタイズし、定位と低域を補正したものと説明されている。[S4c] したがって、完成2mixしか使えないPDRMと同じ入力条件の成功例ではない。サブ波形追加の有無までこの記述から補わない。

### D.O.I.本人の公開分析

D.O.I.はリル・ナズ・X『MONTERO』の分析で、ボーカルの中低域整理と歪みによる倍音の強調、低域の鳴りにくい小型スピーカーで808を伝えるための歪みについて説明している。[S8]

これは他者作品への本人の分析であり、上記KIRINJI／松原みきの制作工程を開示したものではない。PDRMでは『低い基音による重量』と『上の倍音による輪郭・小型再生への伝達』を分ける設計上の参考とする。採用済みCの高域に一律の歪み・明るさを追加する根拠にはしない。

## 3. 混同しない四つの作用

| 作用 | 増えるもの | 本プロジェクトでの位置づけ |
|---|---|---|
| 既存の基音を増幅する | 元からある同じ周波数成分 | 既存低域調整。新規生成ではない |
| 基音を推定して同じ高さの波形を補う | 弱い／欠けた基音 | 基音補完。推定失敗と既存成分の相殺を管理する |
| 既存ベースを1オクターブ下で重ねる | 元の半分の周波数 | サブハーモニック補完。オクターブ追加であり原音の厳密保存ではない |
| 上方倍音を追加する | 基音より高い倍音 | 小型再生向けの輪郭補助。実際のサブロー追加とは別 |

Waves Submarineは入力の音高・フォルマント・包絡から下方オクターブを再合成する機能として説明されている。[S5] 制作者本人の使用例には、必要な音だけへの適用、大型再生向けの実低域と小型再生向け倍音の役割分担がある。[S6]

Little Labs VOGのような低域共振制御は、低域を大きくする道具であっても、それだけで新しいサブオクターブを作ることを意味しない。[S9]

数学上も、HarmonicElasticityのような奇数次の瞬時多項式へ単一正弦波を入れるだけでは、元周波数の半分の成分は得られない。多音入力で生じる差音と、演奏音に従うサブベース生成は別である。この点は本書のDSP上の整理であり、D.O.I.の発言ではない。

## 4. キーは補助情報。制御の主役は実際のベース音列

曲全体のキーは、その時点でベースが何を弾いているかを一意に決めない。分数コード、経過音、半音進行、転調を、グローバルキーへの強制量子化で消さない。

例として、ハ長調でもCmaj7/EのベースがEなら、サブをCへ固定するのでなく、そのEの演奏を尊重する。

周波数の例はA4=440Hzの十二平均律による計算値である。

- E2：約82.41Hz。必要ならE1：約41.20Hzを下に重ねる候補がある。
- E1：約41.20Hzが既に十分あるなら、E0：約20.60Hzを無条件には追加しない。
- 同じ音名でも、楽曲・演奏位置に応じて補完不要という解を残す。

順序は、実音の音高と発音区間 → 前後の音列 → 和声との整合 → キーの補助利用。

理論上のコードルートへベースを置き換えない。既存演奏の微小なチューニング差やピッチ推移も、不要に440Hz基準へ固定しない。

## 5. 改訂する実験契約

以前の『20〜110Hz内に既に存在する成分だけを調整する』制約では、生成しなければ得られない基音／下方オクターブを扱えない。

利用者から今回示された『楽曲を判定してサブローを足したい』という要望を受け、**実験用経路には音楽条件付きの新規低域生成を設計対象として追加する**。

保持する条件：

- 採用Cを固定し、最終出力のベースはCをそのまま通す。
- 新しい旋律・リズム・コード進行を発明しない。
- 同音名の下方オクターブ追加は、今回の新しい低域補完候補として扱う。
- グローバルキーの主音を持続させない。
- 無音・休符をサブで埋めない。長い余韻を勝手に追加しない。
- 110Hz以上の音色変更、ステレオ拡張、HarmonicElasticityの重ね掛けは、この実験へ含めない。
- サブ追加を毎曲必須にしない。不要・不確実な区間はゼロ追加を選べる。

この変更は実験範囲の変更であり、現行DSPの制限をコード上で解除したことを意味しない。

## 6. 実装するべき構造：分析だけ分け、出音全体は置き換えない

```text
採用C ──────────────────────────┐
  │                                             │
  └─ 分析用のベース／打楽器推定                   │
        ↓                                      │
     音高候補・発音・休符・局所和声・確信度        │
        ↓                                      │
     既存基音と不足量の確認                       │
        ↓                                      │
     KEEP / REINFORCE / SYNTHESIZE / ABSTAIN     │
        ↓                                      │
     追加低域レイヤーΔsubのみを描画               │
        ↓                                      │
     位相・包絡・キック同時発音・量の制約         │
        └─────────────────────────＋
                                                 ↓
                                 全曲単位の比較用レベル調整
```

分離した全ステムを再合成して出力する方式は最初の実験には採らない。分離誤差を中高域・ボーカルへ広げないため、分離は分析に用い、出力は原Cと追加レイヤーだけにする。ただし分析の分離誤差が誤った追加音へ転移する可能性は残る。

分析帯域を20〜110Hzだけに制限しない。弱い基音の推定には、その上の倍音も検討する必要がある。

### 状態の扱い

| 状態 | 実験経路の動作 |
|---|---|
| 低域が既に足りる | KEEP：加えない |
| 既存基音があるが弱い | REINFORCE：既存関係を保つ補強候補 |
| 演奏音と発音区間は明瞭だが、望む低域の基音が弱い／ない | SYNTHESIZE：同音高または適切な下方オクターブを補完する候補 |
| 音高が曖昧、キックとの識別困難、短い経過音、過剰な重なり | ABSTAIN：生成しない。例外箇所だけ記録 |

最初の試作はベースに従うレイヤーを優先し、キックの新規低音レイヤーも同時には追加しない。キックは衝突を避けるための制御信号として分析する。ベースが無い曲でキックへ自動的に対象変更するのは別実験とする。

## 7. 音響上の成立条件

### 音程

キーに属するかだけで合格にしない。既存ベース音と同音名か、オクターブ関係か、フレーズに反する跳躍がないかを確認する。複数の音高推定が不一致なら生成量を下げるかゼロにする。確信度スコアを実証前に正答確率として解釈しない。

### 時間

全曲をオフラインで見てから音列・休符を確定する。発音境界には滑らかな包絡を使い、低域の周期に対して短すぎる振幅切替を避ける。次のノートへ余韻を持ち越さず、元のグルーヴの先行／後行を保持する。

### 位相

同じ周波数の既存成分を補う場合は局所的な相殺を避ける。1オクターブ下の成分と元の基音は異なる周波数なので、両者を常時『同相』にするという要求は置かない。初期位相と連続性を候補として比較し、数周期以上の合成波形でピーク・低域の膨張・キックとの干渉を評価する。ピーク最大化を位相合わせの目的にしない。

### 量

参照の20〜60Hz中央値との差を、そのままサブの必要ゲインへ変換しない。曲ごとの最低音と編曲差を許容する。まず既存低域のある区間へ一律追加するのでなく、不足と推定できる区間に限定する。

### 再生条件

全曲−14 LUFSという既存の比較条件を維持する。これは今回のプロジェクトの比較契約であり、全プラットフォームの仕様を断定した値ではない。

追加後に全曲ゲインを下げると中高域も同量下がる。したがって『中高域をサンプル単位で完全不変にしつつLUFSも完全一致』とは約束しない。追加レイヤーの高域漏れと、最終共通ゲインによる変化は別々に記録する。

実際の低域と、小型スピーカーでの低音感は同一でない。最初の実験は実低域だけとし、上方倍音を同時に追加して因果を混ぜない。スマホ内蔵スピーカーだけの無変化を、サブ追加自体の失敗とも成功とも断定しない。[S6]

## 8. 機械的受入と聴感受入の分離

機械的に検証するもの：

- C入力のSHA-256固定、元ファイル無変更。
- 追加レイヤーだけの保存と、同条件での再生成。
- 曲全体と処理単位のcheckpoint、再開、進捗表示。
- 音高誤推定、オクターブ飛び、休符への漏れ、発音前の不要成分のテスト。
- 追加後の真のピーク推定、全曲LUFS、110Hz以上への漏れ、codec復号後の値。
- 処理しなかった区間と理由を含むレポート。

聴感でのみ決めるもの：土台・張り・艶の改善、ボーカル後退の許容、低音の付け足し感、反復試聴時の快適さ。数値だけでこれらをPASSにしない。

開発時はCと処理版の2本を基本とする。通常運用で毎曲A/B/Cを人に選ばせる要件にはしない。自動処理の曖昧箇所は原音維持へ戻し、ユーザーに音符入力・キー修正を毎回要求しない。

## 9. 今回の実施状態

- 完了：公開インタビュー・公式リリース・メーカーの技術説明を確認し、事実と仮説を分離した。
- 完了：『既存低域だけ』から『演奏を条件とする新規低域補完も実験対象』へ仕様文書を改訂した。
- 未実施：新しいDSPコード、実音源からのベース推定、サブ生成、レンダリング、今回の新機能のCI／聴感試験。
- 維持：採用C、本番runtime、既存DSP、既存Round制限。

3視点の合意：制作思想の移植は有用だが、未知のD.O.I.固有手順を捏造しない。演奏情報を制約として新規低域を補う設計は進める。自動推定の正しさと音楽的な価値は実装後に別々に検証する。

残る論点：2mixから十分な確信度でベース音列と不足基音を推定できる区間の割合、増強ではなく生成が必要な範囲、再生環境ごとの最適な追加量。これらを今回の資料だけで確定しない。
