# Note-Sub＋HFTC — 利用者の総合採用判断

日付: 2026-09-05
状態: ACCEPTED_BY_USER_FOR_PERSONAL_WORKFLOW

## 決定

利用者は3曲の試聴を総合し、次の組み合わせを合格・採用と明示した。

- Note-Sub v0.2.1
- HFTC v0.1
- 適用順序: Note-Sub → HFTC
- 重視する価値: 開放感と、反復聴取時の聴き疲れの少なさ。その範囲内での力強さ。

利用者の指示: 「Note-Sub＋HFTC追加版 が合格でいいです。その前提で進めましょう」。

この価値判断を受け、3曲比較の合格保留を解除する。予定していたSong1の段別4条件比較は中止する。同じ聴感採用を決めるための追加試聴・追加曲・追加JSON・doctor・selftestの実行を利用者に要求しない。

## 採用と証拠を混同しない

これは利用者の総合判断による個人制作向け採用であり、既存記録の不明なランダム対応が復元されたことや、旧共通ピーク保護が再現されたことを意味しない。「全曲で追加版が勝利」「特定処理が疲労を医学的に軽減」と記録を書き換えない。以前の選好記録は履歴として保持するが、そこでの採用保留より今回の明示的決定を優先する。

## 今後の実行契約

- 新しい明示起動の一括入口では、両段を既定で有効にする。都度のA/B選択は要求しない。
- DSPの追跡・追加量・HF制御規則は増強しない。既存の無処理判断と数値安全判定を保持する。
- 元音声を上書きしない。既存の採用C/B/Xと本番pdrm_engine / pdrm_runtime / pdrm_operator_labを変更しない。
- HarmonicElasticityを知らない間に再適用しない。一括入口の責務は追加2段と入出力に限定する。
- -14 LUFSへ上げるためにリミッターや別のピーク加工を無断追加しない。必要時は共通ゲインだけで音量を下げ、その値を実行記録へ残す。
- 機械試験は新しい入口の接続・保存・失敗処理の確認であり、聴感採用を再審査する工程ではない。

## 再開条件

実利用で具体的な誤音・破綻・不自然な変化が報告されたときだけ、該当障害へ戻る。現時点で仮説上の可能性を理由に採用を再度保留しない。
