# オフラインピーク処理 — 「元からその音」の品質要求

日付: 2026-09-06
状態: USER_REQUIREMENT_RECORDED / ALGORITHM_PROPOSED / DSP_UNCHANGED
確認した実装基準: b9c66afaadb7702717101c7c0f9e954fba6d6f72

## 利用者の要求

「まるで元からその波形であったかのような、まるで元からその音であったかのような、処理を期待します」

品質目標は、同じ演奏・同じ音色・同じ距離感として聞こえ、立ち上がりから響き、消え際まで加工の継ぎ目を感じさせず、指定LUFSとTrue Peak上限を満たすこと。

自然さをアコースティック化や滑らかさと同一視しない。シンセの角、録音の粒、意図された歪み、狭い定位、乾いた質感も原音の性格として保持する。自然だが別の音になった候補、数値的に近いが不自然な候補の両方を落とす。

## 現在地

現行v2.2のdistribution_finish.pyでは、前段とWAV最終段の両方でpeak.fitを呼ぶ。前段を一定ゲイン中心にする方針は合意済みだが、前段リミッター撤去とオフライン波形最適化はまだ実装・配布していない。

今回変更するのはこの要求記録のみ。新DSP、音声、EXE、試験結果は生成しない。既存Note-Sub/HFTCの採用判断を再審査しない。

## 設計提案

- ピークの先端を一律に丸めるのでなく、その前後の周期・倍音・包絡・左右関係を参照し、小さい加算差分を制約付きで探索する。
- 位相再配置を第一段として全音源へ強制しない。初期試作では自由な位相操作や楽器分離を必須にしない。
- 聴覚マスキングは候補生成の制約・代理評価であり、人間に不可聴という証明にしない。重みとマスキングの基準を元波形から定め、出力自身を都合よくマスカーにしない。
- 短い変更ほど良いとは決めない。差分のスペクトル、前鳴り、接続部、元の不規則さを別々に評価する。
- 原音の立ち上がり前、休符、最終余韻、低域周期、定位・モノ合成の変化に保護条件を置く。
- 原音の録音時に存在した別の波形を復元したとは主張しない。元2mixの知覚的同一性を保つ出力の探索とする。

## 最適化の境界

入力rに対してy=a*r+dを求める。aは一定ゲイン、dは形状変更差分。LUFSとTPの両方を満たし、同じ音としての関係性を保つことを目的にする。

固定したゲイン・解析窓・重みの部分問題には凸な構成を選べるが、ゲート付き全曲LUFSや位相・包絡を含む問題全体が凸であるとは主張しない。元の同じrを参照して有限回の探索と書出し後の再測定を行う。

TPはサンプルピークだけでなく補間推定で確認する。LUFSの既存工学的許容±0.03 LUは保持する案とするが、自然さの閾値とは混同しない。4x/8x推定の合格を全再生系の保証へ拡張しない。

条件を満たせる一定ゲイン解があれば波形変更を追加しない。達成できない場合、通常リミッターへ黙って切替えたり、指定LUFSを勝手に下げたりして新方式成功と呼ばない。

## 前段変更の注意

現行Note-Subには−14 LUFS参照やレベル依存の判定がある。前段peak.fitを単に削除するだけでは検出・追加量の条件まで変わり得る。分析上の基準レベルと描画レベルの対応を設計し、途中の再正規化で安全余裕を失わないようにする。

新旧最終ピーク方式を比較するときは、同じ前段出力を両方へ渡す。前段削除と新ピーク方式の効果を一つの比較で一括認定しない。

## 受入条件

1. 音楽的同一性: 打撃と胴鳴り、子音と母音、音程移動、余韻、センターと周辺の関係を損なわない。
2. 加工の痕跡: 前鳴り、別の金属音、背景の呼吸、周期の乱れ、余韻切断、音像の揺れを追加しない。
3. 数値・保存: 指定LUFS/TP、有限値、長さ・レート・チャンネル数、元音源不変、同名processed保存を満たす。

一つの良い平均スコアで他の保護条件の破綻を相殺しない。通常リミッターのゲインリダクションP95が小さいだけで自然さを認定しない。

機械試験と本人の知覚判断を区別する。既存音源から内部で候補を絞り、必要なときだけ少数の比較を行う。同じ採用判断の反復、追加JSON要求、全曲が勝つまでの調整を再開しない。

## 前の説明の修正と根拠

通常のalimiterも先読みを使う。オフラインの価値は、未来を全く見ない処理との対比ではなく、長い文脈・候補比較・反復計算の利用にある。

Jeannerotらは聴覚マスキング制約下のピーク最小化を報告している。ただし全楽曲・全再生条件での不可聴、PDRMの実装や聴感成功は証明していない。

Defraeneらの知覚的クリッピング研究は凸最適化・心理音響モデルとリアルタイム実行を扱う。波形最適化をオフラインだけの新発明とはしない。
