# Offline Peak Lab v0.1 — 波形差分最適化の初回試作

日付: 2026-09-06
状態: EXPERIMENTAL_WAVEFORM_CANDIDATE / NOT_LISTENING_VALIDATED
基準: c6dd89ec7bebcf20a368f88d450571675228e3aa

## 今回の実装

既存EXE、GUI、Note-Sub、HFTC、HarmonicElasticity、distribution_peak、前段の音量準備を変更せず、独立したoffline_peak_lab.pyを追加した。本番入口からは呼ばない。

最終ピーク段への同一入力rを参照し、y=a*r+dを求める。aは全体の一定ゲイン、dは加算する差分波形。新方式ではalimiter、位相回転器、最終クリッパーを呼ばない。数値未達や代理保護ゲート不成立を既存リミッターで救済しない。

42.67msの重なり窓を4倍の分析格子へ補間する。固定した参照窓から周波数重み・時間重み・左右関係を計算し、正定値二次目的とボックス制約の部分問題を射影付き加速勾配法で解く。重みの参照を出力自身へ更新しない。

元に弱い周波数へ差分を置くこと、低域の変更、静かな場所への差分、元の瞬間的な左右方向から外れる差分へペナルティを設ける。デジタル無音の元サンプルは保持する。ゲインだけで条件を満たす場合は波形最適化を使わない。

周波数重みは原音のスペクトル包絡に基づく未較正の代理モデル。Jeannerotらの心理音響モデルを再実装したものではない。完全な聴覚マスキング、楽器の意味識別、長時間のイベント同一性、全ての前鳴り・定位変化の保証は実装済みではない。

## ピーク制約の扱い

4倍格子上でのボックス制約を満たしても、元サンプル位置への復帰・窓の合成後にTP条件を破る場合がある。そのため、最終波形を4倍と8倍補間で測り、LUFSとTPを同時に検査する。外側の探索は最大5回、同じ原参照から描画し直す。原音へ追加クリップを重ねない。

今回の返事は私の初回探索は−1.9902 dBTPで失格となり、同じ参照から内部天井を下げて再描画した2回目が−2.0356 dBTPで成立した。初回の格子合格を最終成功と誤認していない。

書出し後にもLUFS/TP、長さ、サンプルレート、有限値、原音ハッシュを確認する。工程失敗時は診断を残すが、音声を完成候補として公開しない。実験用保存は既存同名結果を上書きしない。現行EXEのprocessed保存へ接続したという意味ではない。

## 混合音回帰

新規25件。既知ベース・キック・高域打撃の混合、ゲインのみ、無音、正確な無音位置、モノ／逆相、片チャンネル無音、決定性、入力非破壊、サンプル間ピーク、窓境界、二次目的の低下、残差予算不成立、ゲイン予算、保存後照合、失敗時未公開、既存出力保護等。

初回のゲイン予算テスト信号は測定の絶対ゲートより下にあり、予算判定前に無音として拒否された。入力信号のレベルだけを変更して予算拒否の経路を検査した。アルゴリズムや実曲の許容閾値を、合格のために変更していない。

合成試験は機械動作の確認であり、聴感の合格ではない。CI実行数・成否はActionsと生成結果JSONを参照。

## 実曲比較の範囲

提出済みの「返事は私」と「Traces」から、いずれも00:40–01:04の24秒を取り出した。区間は新最適化の計測前に固定し、良く見える区間を探索して選んでいない。各区間を独立して処理・音量測定している。全曲処理から切り出した結果でも、全曲−12 LUFS達成でもない。

各区間の共通入力は、現在のHE→共通ピーク準備→Note-Sub→HFTCを通したもの。その同一PCMを現行alimiter方式と新方式へ渡す。前段リミッター撤去の効果を混ぜない。新方式の最終段は通常リミッターなしだが、前段までリミッター不使用という主張ではない。

前段ゲイン中心への変更は別工程として未実装。この比較の結果でNote-Sub/HFTCの採用判断をやり直さない。

| 区間 | 新方式 LUFS-I | 新方式 TP推定 | 現行 LUFS-I | 現行 TP推定 |
|---|---:|---:|---:|---:|
| 返事は私 40–64秒 | -12.001115 | -2.035633 | -12.000000 | -2.109014 |
| Traces 40–64秒 | -12.003663 | -2.032177 | -12.000000 | -2.133288 |

数値は4x/8x補間による推定。認証測定器や全再生系の保証ではない。

## 同一参照に対する記述的比較

共通入力を一定ゲインだけで−12 LUFSへ揃えた参照から比較した。差分はサンプル誤差であり不可聴性スコアではない。20ms包絡はL/R平均パワーの20ms移動平均を10ms刻みで比較し、有効区間における絶対dB差のP95を計算した。

| 区間 | 参照との差分RMS：現行→新方式 | 20ms包絡変化P95：現行→新方式 |
|---|---|---|
| 返事は私 | -23.27 → -40.32 dB | 0.951 → 0.028 dB |
| Traces | -22.90 → -37.64 dB | 0.857 → 0.018 dB |

これらは参照へ近いという数値上の手掛かりで、知覚的に自然、聴き疲れが少ない、全面的に現行より優れるという確定ではない。最適化した種類の誤差で自方式が良く見えるバイアスにも注意する。

## 試聴と対応表

試聴用は新旧とも一定ゲインで−16 LUFSへ下げ、24-bit/48kHzのWAVとして保存した。最終ピーク処理をしない共通入力のREFERENCEも同じ音量で用意した。試聴用には追加リミッターを使わない。

曲ごとにX/Yを無作為割当。対応表は別のReveal ZIPへ保存し、試聴ZIPへ混ぜない。対応表には、ラベル・役割・試聴ファイルhash・処理後マスターhash・共通入力hashを含めた。後の回答で対応が分からなくなることを避けるため、Reveal ZIPもチャットから保存できるようにする。音声本体はGitHubへアップロードしない。

## 未実施

全曲の新最適化完走、前段リミッター撤去、現行GUI/EXEへの統合、他の目標値範囲全体の検証、聴覚モデルの較正、本人の聴感合格。初期の全曲共通入力生成はチャットの時間制約で中断しており、成功結果へ含めない。

入力を全体配列で読む研究版であり、長時間音源のメモリ上限・中断再開・多重実行ロック等を配布EXEと同等に完成した版ではない。完成音へ正式採用する前に、実音の判断とその接続を別に確認する。

## 根拠と実装の区別

- Jeannerot et al., arXiv:2202.08183。参照に対する周波数重み付き差分とピーク制約の研究方向を確認。今回の重みや合否値は論文の値ではない。
- SciPyのFFT・resample_polyを数値演算へ使用。
- 現行対照はrepoのdistribution_peak.pyのfit、同じLinux環境のFFmpeg 7.1.5を使用。Windows配布EXEのバイナリそのものをLinuxで実行した結果ではない。

本研究版の出力が数値ゲートを通過しても、「元からその音」の品質契約全体を自動的に満たしたとは扱わない。
