# PDRM OPPO v3.0 — 全曲オフライン波形最適化

日付: 2026-09-06

## 起動

ZIPを旧版とは別のフォルダにすべて展開し、`PDRM_OPPO.exe`を起動します。EXEだけを抜き出さず、`_internal`・`LICENSES`・`SOURCES`も保持してください。Python・FFmpegの追加インストールは不要です。

WAVとMP3のLUFS-I・True Peak上限を設定し、「この設定で開始」を押して元のステレオWAV/FLACを選びます。複数選択できます。初期値はWAV −12 LUFS / TP上限−2 dBTP、MP3 −14 LUFS / TP上限−2 dBTP。4項目の値は次回も記憶します。

## 前段を明示選択

- **一定ゲインのみ（前段リミッターなし）**: 毎回の初期選択。HarmonicElasticity → 一定ゲイン準備 → Note-Sub → HFTC → OPPO。前段・最終段・MP3分岐とも通常リミッターを使いません。
- **比較時と同じ前段ピーク整形（明示的な互換モード）**: 前段だけ旧−14 LUFS / −2.5 dBTPのピーク整形を使用。最終段とMP3分岐はOPPOです。過去のX/X区間比較に使った前段条件に対応します。

互換モードは利用者が処理開始前に選択する別経路です。ゲインのみの処理が失敗した後に自動切替することはありません。前段の選択は、次回起動時にはゲインのみへ戻ります。

## 全曲試験で分かった適用限界

提出済み3曲を全曲処理しました。−12 LUFS / −2 dBTPのWAVと−14 LUFSのMP3について、ゲインのみの前段では「私=AI-MY」「Traces」は完成しました。「返事は私」は58.816–58.859秒付近で、選好された元方式の局所差分上限を超え、不成立として停止しました。

「返事は私」は、前段を上記の互換モードに明示設定した別試験で全曲出力に成功しました。この結果を、前段リミッターなしで3曲とも成功したとは扱いません。許容閾値を緩めたり、通常リミッターで最終段を救済したりしていません。

数値目標が厳しい場合は、同様に不成立となる曲があります。LUFS/TPの入力範囲内であっても全ての組合せを達成できる保証はありません。目標の引下げや別方式への切替を黙って行いません。

## 出力先

```text
音源フォルダ/
├─ 曲名.wav                  元音声は保持
└─ processed/
   ├─ 曲名.wav               設定したLUFS/TP・24-bit PCM
   ├─ 曲名.mp3               設定したLUFS/TP・320kbps
   └─ .pdrm/                 整合記録と必要時のバックアップ
```

MP3は完成WAVから作ります。定数ゲインだけで満たせる場合は波形変更を追加しません。MP3独自の条件に追加ピーク制御が必要なら、その分岐もOPPOを使用し、完成WAVは変更しません。復号後にもLUFS/TPと長さを検査します。

WAVは入力の44.1/48/88.2/96 kHzを維持。高レートのMP3は48 kHzへ変換します。LUFS-I許容は±0.03 LU、TPは上限であり必ず天井まで上げる目標ではありません。4倍/8倍補間による数値推定で、全再生系の保証ではありません。

## 途中再開・上書き保護

元音源を再度選び、同じ設定・前段で実行すると、確定済みチャンクや中間音を照合して再利用します。処理中にコンソールでCtrl+Cを押した場合も、元音源から再実行してください。チャンクごとの音量合わせはしません。

既存のPDRM出力を別設定・別方式で作り直す場合は、画面の「既存のPDRM出力を退避して、同じ名前で作り直す」を選びます。新しい音声の検査に成功してから旧出力を`processed/.pdrm/backups/`へ保存します。手動編集した出力、管理記録のない同名ファイル、元音源は上書きしません。

不成立の場合は完成WAV/MP3を公開せず、既存出力を保持します。前段を含む実行モードは記録とキャッシュ識別子に含めます。

## 処理量・配布の境界

対応は0.5秒〜30分のステレオWAV/FLACです。全曲波形を一括でメモリに置かず、音声バッファを分割しています。ただし音符情報と短時間包絡ベクトルは曲長に応じて増えます。メモリが常に一定量で済むとの保証ではありません。

中間WAV・再開用チャンクは `%LOCALAPPDATA%\PDRM_Local_Render_Engine_v1\oppo_finish_v3` に保存します。入力の数倍以上の作業ディスクを使用するので空き容量が必要です。進捗はコンソールに表示します。

Windows x64用のPyInstallerフォルダ配布です。コード署名はありません。保護機能を無効化せず、入手元と同梱ハッシュを確認してください。ライセンス・第三者ソースは削除せず配布します。

## 変更したもの・維持したもの

選好された `offline_peak_lab.py` の重み・制約・波形ソルバーは変更していません。全曲の固定ゲイン、固定した解析窓位置、分割I/O、途中再開、前段レベル対応、GUI接続を追加しました。

同じ共通入力の旧24秒候補との最大波形差は約2.98e-8で、FLOAT保存丸めの範囲でした。これは同じ前段入力に対する照合です。前段ゲインのみへの変更まで、以前の試聴で選好済みだったという意味ではありません。

Note-SubとHFTCの採用は維持します。分析上の−14 LUFS参照と、安全な実描画レベルを分け、音符の振幅を対応する倍率へ戻して描画します。前段からリミッターを外した影響と、最終波形方式の影響は区別します。

旧EXE v2.2は保持してください。今回の新方式が全曲・全設定で常に自然であるという保証はしていません。機械試験と実曲数値結果は実装の成立範囲を示すもので、全曲の聴感承認そのものではありません。
