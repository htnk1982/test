### HarmonicElasticity

公開実装の既定写像は以下。

```text
y = x - a*x^3 + q*a^2*x^5
a = 0.105
q = 0.30
```

したがって既定値では:

```text
y = x - 0.105*x^3 + 0.0033075*x^5
```

これは奇対称の振幅写像であり、対象の通常振幅範囲では小振幅に対する作用が小さく、大振幅の相対ゲインを穏やかに下げる。単なる一定ゲインではない。

実験経路には4倍アップサンプリング、非線形写像、ダウンサンプリング、全曲LUFSによるゲイン調整がある。時間定数付きコンプレッサーは使っていないが、振幅依存の圧縮性まで否定するものではない。

単一正弦波に対しては3次・5次項が基音と奇数次成分を変える。複合信号では多項式展開に交差項も生じる。従って「倍音だけを独立に足した」「艶の原因が奇数次倍音と確定した」とは言えない。

PeakProtectedLoudnessにも、小〜中振幅への非線形ゲインに加えて3次項がある。二つの候補を『密度だけ』『倍音だけ』と完全に直交した操作と扱うのは不正確。

この記録の係数は公開実装の既定値であり、今回のローカルmanifest照合による設定証明ではない。

## 4. 新たに見つかった比較経路の交絡

`round9.py` の分岐を確認すると:

```text
Control_Round8A:
  level-matched control -> PCM_24 -> MP3

HarmonicElasticity / PeakProtectedLoudness:
  level-matched control -> 4x resample -> nonlinear transfer
  -> downsample -> LUFS match -> PCM_24 -> MP3
```

Controlだけがアップ／ダウンサンプリング経路を通っていない。
SciPyの`resample_poly`はFIR低域通過フィルタを含むため、写像を恒等関数にしても経路全体は厳密な無変化とは限らない。

従って:

- Cという出力全体が好まれたという選択は有効。
- C対Bだけから改善を非線形写像のみに帰属することはできない。
- AとCは同じリサンプリング経路を共有するため、C>Aは写像の違いを検討する材料になる。ただし最終ゲインとエンコード後の差も残る。
- リサンプリングが今回の主因だったとも断定しない。寄与量は未測定。

さらに、確認した版の主要metricsはMP3エンコード前の配列を測定している。実際に聴いたMP3の復号後LUFS・peak・差分がこのターンで検証されたわけではない。

## 5. 決定

1. 今回のCを試聴基準として保持する。好みの判定を機械指標で覆さない。
2. Cの強度を自動的に上げない。今回の順位は最適強度を同定していない。
3. Aは次点として保持するが、『ボーカルに効いた部分』が分離できたと見なしてCへ混ぜない。
4. Bは対照として保持する。削除も、元2mixという再ラベル付けもしない。
5. Runtime / Safety Shell / production Round 9 lockはこの決定で変更しない。
6. 運用時に毎曲A/B/Cを人間に選ばせる仕様には戻さない。これは開発時の校正である。
7. 『疲れない』だけを目標にして小さく引っ込んだ音へ退却しない。大きさ・張り・艶・抜け・低域の底を、疲労を増やさず両立する要求は継続する。
8. 今回は艶、低域の底、配信リファレンスとの競争力がすべて解決したとは判定しない。

## 6. 次工程 — 新技法追加より先に経路を監査

次に比較可能にすべき経路は三つだけ。

| 経路 | 操作 | 目的 |
|---|---|---|
| Dry control | 同じ入力、非線形なし、resampleなし | 現状の基準 |
| Resample-only control | 同じ4x上げ下げ、写像は恒等関数 | FIR経路だけの寄与 |
| Current C | 同じ4x経路、今回のHarmonicElasticity | 非線形写像を含む寄与 |

入力、長さ、開始位置、最終ゲイン基準、PCM量子化条件、MP3設定を揃える。既存Cは保持し、新しいMP3を再び元音源にして世代を重ねない。利用可能なロスレス入力を優先し、MP3しかなければそれを明示して一度だけ復号する。

先に合成信号と既存出力の機械的監査を行う。確認項目は経路差分、chunk境界、レベル依存性、peak、エンコード前後のLUFS差。これらを『疲労の直接測定』と呼ばない。

意味のある経路差が残る場合だけ短区間の追加試聴を設ける。開示前に候補名を聴感から予想しない。原理候補を増やすためだけの全曲3本レンダリング、自己試験や環境設定の無条件やり直しはしない。

このターンの完了範囲は決定記録と実装監査。新しい音源生成、経路比較の実測、production設定更新は実行していない。

## 7. 3視点の結論

**聴覚評価:** Cを選ぶ。前進量より反復試聴の快適さが優先された。ただし他の要求を達成したという評価は補わない。

**DSP:** Cは弱い波形整形を含む有効候補になった。効果を『倍音が艶を作った』の一因に還元しない。

**検証:** 出力の採用判断と原因の同定を分ける。欠けていたresample-only対照を先に扱い、必要なときだけ追加の耳判断を求める。
