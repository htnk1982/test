## 1. 決定

**C＝HarmonicElasticityを、今回の素材に対する採用音・次の比較基準として保持する。全曲LUFS合わせとリサンプリング経路の監査は、ここで一区切りとする。**

今回の監査だけを理由とする追加試聴、再インストール、selftest／doctorの繰り返しは求めない。

採用根拠は利用者の選好 C > A > B。監査は数値的な再現性と比較経路を確認するものであり、聴感品質や疲労の客観的な合格証ではない。

| ラベル | 処理 | 既報の選好 |
|---|---|---|
| C | HarmonicElasticity | 最も疲れず、うるさくない。今回の採用音 |
| A | PeakProtectedLoudness | 次点。ボーカルの張り出しは良いが、音域感とハイハットに留保 |
| B | Control_Round8A | 今回の三候補では最も前に出るが、うるさく、反復試聴に不向きと評価 |

Bは元の未加工2mixではなく、以前のラウンドで選ばれた比較基準である。このレポートから過去の全処理履歴の正しさまで逆算しない。

**測定された波形変化の主な部分は、フィルタ往復単独ではなく、非線形写像を有効にした経路と、それに伴う最終レベル調整の側にある**と読むのが妥当である。

この大小関係を、改善の寄与率、疲れなさの原因比率、可聴性の証明には変換しない。フィルタの寄与が完全にゼロ、あるいは知覚的に無関係と証明したものでもない。

前段の合成正弦波試験では高域端の減衰を確認していたが、その結果だけから今回の楽曲の変化を大きく見積もるべきではなかった。今回の実音源測定を、今後の判断の優先証拠にする。

出典: AUDIT_REPORT.json lines 269–292。32.643dBは同資料の数値の差として算出。

## 5. 広帯域の高域カットでCを説明する根拠も弱い

同じLUFSへ調整したPCMの帯域平均エネルギー差 C − Dryを、レポートの各band_power_dbfsから引き算すると以下になる。

| 帯域 | C − Dry dB（概数） |
|---|---:|
| 20–80 Hz | +0.000504 |
| 80–200 Hz | -0.002362 |
| 200 Hz–1 kHz | +0.007907 |
| 1–4 kHz | -0.004365 |
| 4–8 kHz | -0.004042 |
| 8–12 kHz | +0.007082 |
| 12–16 kHz | +0.008274 |
| 16–20 kHz | -0.032234 |

測定した20Hz〜16kHzの各帯域平均差はすべて0.01dB未満。16〜20kHzも約−0.032dB。

従って、少なくともこの帯域平均値からは、Cを『広く高域を削って聴きやすくした音』とは説明しにくい。時間局所・狭帯域の違いや、利用者の聴感上の音域感まで否定するものではない。

出典: AUDIT_REPORT.json lines 4–23, 213–267。

## 8. 未確定事項と次の判断

未確定なのは、奇数次倍音が艶や疲れなさの主因であること、別曲でも同じ効果が出ること、Cが配信比較先の大きさ・抜け・低域の底・艶へ到達したこと。今回のJSONにはリファレンス比較がない。

従って次の研究の問いは、『Cの何をもっと加工するか』ではなく、**『Cを基準にして、配信比較先に対しまだ不足している知覚品質は何か』**に戻す。

このレポートだけからAとの混合、強度増加、HF処理や低域処理の追加を決めない。Cの採用と、全自動finalizerの完成を混同しない。日常の運用で毎曲利用者にA/B/Cを選ばせる仕様には戻さない。
