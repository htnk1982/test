# LocalScribe — 同梱GUIの開発候補

Python・モデル・実行部品を同梱して、Windowsで配布物からの起動、GUI、CPU認識、Markdown保存を検証する候補です。

実行するには `LocalScribeNPU.exe` を開き、0.1〜30秒のWAV/FLACを選択し「開始」を押します。
モデルは隣接する `models` を参照します。ダウンロード、インストーラー、自動更新、クラウド認識、録音機能はありません。
入力音声は変更せず、開始ごとに別の出力フォルダを作ります。以前の結果は上書きしません。

**これはNPU受入用の配布版ではありません。** 処理は一つのプロセス内で行い、中止は現在の処理が戻るまで待機する予約です。
ネイティブのモデル準備を途中で強制停止する機能や、20分の強制時間上限はありません。
ライブ入力、対象NPU性能、実会議精度、Wisp比較も未達です。

開発用の `--exercise` オプションは、指定した公開サンプルを用いて、実際のTkボタンをイベントループ内から呼ぶ結合試験です。
OSへの入力注入、他のプロセスの起動・終了、ファイアウォール変更はアプリに含みません。

保存先の `transcript.md` が本文、`result.md` が技術結果、`_private_error.txt` が私的な例外詳細です。
共有前に内容を確認してください。`_private_` ファイルにはパス等が含まれます。
保存先が同期フォルダなら、別の同期機能でデータが複製される可能性があります。

開発上のCPU結合試験に通っても、製品完成・NPU受入・公開Releaseの承認にはなりません。
