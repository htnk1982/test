# LocalScribe NPU 0.5.0 — 同梱候補

この版はNPU固有の実行可否を確認するファイル入力版です。ライブ文字起こしの完成品ではありません。

ZIPをすべて展開し、LocalScribeNPU.exeを起動します。0.1〜30秒のWAV／FLACを選び、NPUで開始してください。音声原本は読み取りだけで変更しません。認識2回の時間とモデルの準備時間を分けて記録します。

- NPU/GPUは全体900秒、CPUは120秒で打ち切ります。中止後は通常数秒で操作へ戻ります。
- NPUドライバーやWindows全体の停止はアプリだけでは回復できません。
- 出力先はWindowsのドキュメント内LocalScribeNPUです。同期フォルダなら別途同期されえます。
- transcript.mdは本文、result.mdは自動マスク済み技術情報です。共有前に確認してください。
- 音声を録音せず、クラウドへ送らず、モデルの自動取得やドライバー変更をしません。
- NPU指定の成功は内部各部の実行先を計測した証明ではありません。
- 失敗・中止・タイムアウトでCPUへ自動変更しません。
- Windows 11 x64とOS標準の.NET Framework 4.8以降を使用。Python/pipの導入は不要です。
- 未署名の開発候補です。会社の保護機能が禁止したら無効化せず中止してください。

NPU、ライブ入力、一般的な精度、Wisp比は未検証です。開発用のテストが成功しても完成版とは扱いません。
